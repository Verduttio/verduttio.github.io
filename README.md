# verduttio.github.io

Personal website built with React, TypeScript and Vite.

## Requirements

- Node.js
- npm

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the URL shown in the terminal.
   Vite usually starts on `http://localhost:5173/`.

## Build for production

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Deploy to GitHub Pages

1. Make sure your changes are committed and pushed.
2. Run:

```bash
npm run deploy
```

This command builds the project and publishes the `dist` folder to the `gh-pages` branch.
